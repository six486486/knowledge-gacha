# 隐私与数据流

## 数据保存在哪里

卡片、偏好、复习记录、伴学会话、保留的原文和向量索引保存在当前浏览器扩展的本地 IndexedDB 中。项目没有账号云同步或自建远程学习数据库。

模型地址和名称保存在本地设置中。API Key 默认仅保存在当前会话的 sessionStorage；选择记住密钥后保存在 localStorage。浏览器本地存储不是加密保险箱，能控制当前浏览器或设备的人仍可能读取它。

发布的源码和扩展 ZIP 不包含任何用户的模型配置或学习数据库。`manifest.json` 中的 `key` 是用来稳定扩展 ID 的 **RSA 公钥**，不是模型 API Key，也不是私钥。

## 什么会发给模型

生成、伴学、模型连接测试等操作会将所需输入和相关上下文发送给用户配置的 Provider。API Key 用于向该 Provider 认证。选区、网页或图片的读取由用户主动触发；扫描页识别会发送选定图像。

启用相关范围时，请求可能包含当前材料、检索命中的有限片段、明确偏好和学习记录。伴学的知识库、使用偏好、参考学习记录分别可关闭。关闭后限制新的读取，已经发送的内容无法撤回。

BGE 检索模型和解析器随扩展打包，向量计算及普通 PDF/DOCX 解析在本地执行，不需要模型 API Key。首次使用生成服务时，扩展按需申请该服务域名的访问权限。

## 控制与清理

- 在“更多 → 我的模型”修改或清除密钥。
- 在“我的学习偏好”停用、删除偏好，或清除近期推荐上下文。
- 在“本地数据与隐私”清理学习数据；删除浏览器扩展也会影响本地保存的内容。
- 运行记录只显示脱敏后的状态和摘要。分享错误报告前仍应自行检查截图及附件。
